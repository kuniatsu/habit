# habit

## 開発内容
flutterで開発するXプラットフォームアプリ
iOSとAndroidで利用可能なアプリ
ストア公開を目指して作成。

## 概要
習慣的に実施したいタスク(habit)を、時次、日次、週次、月次で設定可能。
設定した日時になるとローカル通知でアラートが出る
アラートにはボタンがあり先送るか実施開始選んでアラートを消すことになる。

## アラート
実施開始の場合は、そのhabitに設定されているアプリがそのままディープリンクで遷移する。
例: 「タイトル: 久しぶりの友人への連絡」「本文:その友人は誰ですか、何を送ったら面白い？」「ボタン: 実施」「遷移先: LINE」
また先送りには厳しく、実施してないとすぐ次のアラートがなる時次なら5分後、日次なら１時間後、週次なら次の日、月次なら次の週。
次のhabit実施時間まで先送りが続いたら逃げ切りになるが、次のhabitにまた追われる。

## UI
限りなくシンプル。
TOPには、habit一覧、次のhabitがいつかわかる。
登録画面はhabitの登録ができる。
habit履歴は消化したhabitが並ぶ。
フッターメニューがあり上記３つのボタンが並ぶ

登録画面に遷移する前に事前に用意してたhabitを選べる。一番上にカスタムhabitというhabitがありそれを選ぶとオリジナルのhabitが作れる。
habitのアラート表示メッセージは読んだら行動を想像してしまうメッセージにする。
×メッセージを送りましょう
